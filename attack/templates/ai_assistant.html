OWASP Top 10 for LLM Applications (2025)

Official checklist (10 risks): OWASP PDF · GenAI hub

The following checklist items are exercised in this DevNotes build.

  • LLM01:2025 Prompt injection. Crafted user input and RAG-retrieved content override system and developer instructions, causing unintended model behavior.
  • LLM02:2025 Sensitive information disclosure. Secrets present in prompts, RAG context, and logs such as API keys and tokens are exposed through model responses and logging.
  • LLM03:2025 Supply chain. Risks from third-party dependencies including Python packages defined in requirements.txt, external models, and datasets used by the application.
  • LLM04:2025 Data and model poisoning (RAG). Malicious note content is embedded into the vector store and later retrieved into the model prompt.
  • LLM05:2025 Improper output handling. Model-generated and RAG-retrieved content is treated as trusted and rendered in the web interface without sanitization, enabling execution of attacker-controlled code.
  • LLM06:2025 Excessive agency. The model triggers application actions such as importing external content without validation and without user confirmation.
  • LLM07:2025 System prompt leakage. System and developer instructions are not isolated, allowing hidden prompts and internal data to be exposed in model responses.
  • LLM08:2025 Vector and embedding weaknesses (RAG). Retrieved data from the vector store is trusted without validation, filtering, and provenance checks, allowing malicious content to influence responses.
  • LLM09:2025 Misinformation. Poisoned and incorrect RAG content leads to inaccurate responses presented as authoritative.
  • LLM10:2025 Unbounded consumption. The application does not enforce limits on prompt size and request rate, where oversized prompts and rapid requests return HTTP 503 without invoking the model.
