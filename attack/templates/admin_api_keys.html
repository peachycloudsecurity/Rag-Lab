Security Vulnerabilities Demonstrated

This page demonstrates critical vulnerabilities:

  • A09 - Logging Sensitive Data: API keys logged in plain text in api_keys.log
  • A01 - Broken Access Control: Admin can see ALL API keys in full (should only see hashed versions)
  • A09 - Excessive Logging: IP addresses and User-Agents logged alongside keys
  • A08 - Data Integrity: Log file accessible and contains sensitive data
  • Risk: Anyone with file system access can steal all API keys

Proper Implementation:

  • ✅ Never log API keys, passwords, or tokens in plain text
  • ✅ Store only hashed versions of API keys in database
  • ✅ Log only partial/hashed versions for audit trail
  • ✅ Encrypt log files or store in secure logging service
  • ✅ Implement log rotation and retention policies
  • ✅ Restrict log file access to authorized personnel only
